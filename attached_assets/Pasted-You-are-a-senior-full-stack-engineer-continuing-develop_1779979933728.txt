[ 32 ] SKILL REELS
  - 60-second vertical video clips users record to showcase a skill
  - Scrollable TikTok-style feed on the Discover page (separate tab from swipe cards)
  - Viewers can react (🔥 Impressive / 🤔 Curious / 👏 Taught me something)
  - Reactions accumulate into a "Reel Score" shown on the user's profile
  - Stored in Firebase Storage at /reels/{userId}/{reelId}
  - Firestore doc at /reels/{reelId}: { userId, skillTag, duration, uploadedAt, reactions }

[ 33 ] SKILL AUCTIONS
  - Users can auction a limited 1-on-1 session slot
  - Other users bid using credits within a 24-hour window
  - Highest bidder wins the slot; credits are transferred on close
  - Live bid counter + countdown timer on the auction card
  - Auctioneer can set a reserve (minimum) credit price
  - Firestore collection: /auctions/{auctionId}

[ 34 ] STUDY ROOMS
  - Persistent group spaces (up to 6 people) focused on a shared skill topic
  - Members can join/leave; room has a shared pinboard (text + image pins)
  - "Ambient" presence indicators — show who is currently in the room
  - Scheduled study sprints: set a timer, everyone works silently, end with a check-in
  - Rooms discoverable via Discover page with topic tags
  - Firestore: /studyRooms/{roomId}, /studyRooms/{roomId}/members, /studyRooms/{roomId}/pins

[ 35 ] SKILL DNA
  - After 3+ completed exchanges, generate a personalised "Skill DNA" card
  - Visual radar/spider chart showing skill dimensions (Depth, Breadth, Teaching, Speed, Curiosity)
  - Scores derived from session feedback and ratings the user has received
  - Card is shareable as an image (html2canvas export)
  - Displayed prominently on the user's Portfolio profile

[ 36 ] COLD-START CHALLENGES
  - New users with 0 exchanges are shown a daily micro-challenge on their Dashboard
  - Examples: "Explain React hooks in 3 sentences", "Teach one thing in a 30-sec voice note"
  - Completing a challenge earns +5 credits and unlocks their first badge
  - Challenges generated by Claude API based on the user's listed skills
  - After 3 completions the widget auto-hides and is replaced by normal Dashboard content

[ 37 ] ASYNC VOICE NOTES
  - Inside any chat thread, users can record and send short voice notes (max 90 sec)
  - Stored in Firebase Storage at /voiceNotes/{chatId}/{noteId}
  - Waveform visualiser rendered on playback (use Web Audio API)
  - Auto-transcribed by Claude API; transcript shown below the waveform in collapsed state
  - Transcripts are searchable within the chat

[ 38 ] SKILL CAPSULES
  - Users create a "Skill Capsule": a structured mini-course of 3–5 micro-lessons they authored
  - Capsule has a title, cover image, skill tag, and difficulty (Beginner / Mid / Advanced)
  - Other users can enrol, track progress (lesson by lesson), and leave a capsule review
  - Enrolment costs 3 credits; creator earns 2 credits per enrolment
  - Firestore: /capsules/{capsuleId}, /capsules/{capsuleId}/lessons, /capsules/{capsuleId}/enrolments

[ 39 ] REPUTATION STAKING
  - When a user vouches for another user's skill, they stake 5 of their own credits
  - If the vouched user later receives 2+ negative reviews on that skill, the stake is lost
  - If the vouched user maintains a ≥4★ rating after 5 sessions, the staker earns +8 credits back
  - Vouches appear on the profile as "Staked endorsements" with the voucher's name + stake amount
  - Firestore: /vouches/{vouchId}

[ 40 ] LIVE SKILL DROPS
  - Users can announce an unplanned live session ("dropping in 10 minutes — React hooks Q&A")
  - A push notification goes to all users who have that skill in their "want to learn" list
  - Drop appears on a dedicated "Live Now" banner at the top of the Discover page
  - Sessions auto-expire if not started within 30 minutes of announced time
  - Firestore: /liveDrops/{dropId} with TTL enforced via Cloud Function

[ 41 ] SKILL WRAPPED (MONTHLY)
  - On the 1st of each month, generate a personalised "Your Month in Skills" summary card
  - Includes: top skill taught, top skill learned, credits earned/spent, longest streak, new badges
  - Rendered as a swipeable 3-slide story format (like Instagram Stories)
  - Shareable as an image export
  - Data pulled from existing Firestore collections — no new data model needed
  - Claude API writes the copy in a witty, personalised tone
